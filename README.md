# 📚 C++ 個人動態讀書計畫產生器 (Study Planner)

- **開發語言**：C++ (C++11)
- **開發動機**：解決個人考前時間分配不均的真實痛點（自發性開發專案）
- **核心技術**：`<ctime>` 日期運算、Credit 動態配節演算法、`<fstream>` 檔案讀寫、步驟回溯控制

---

## 💡 開發起源與想解決的問題

這個專案的起因不是學校作業，而是我在準備考試時自己遇到了讀書排程的難題。

在準備段考與模擬考期間，我發現傳統的排程方式（例如平均分配時間，或是硬性規定每天讀哪科）很不彈性：我常常不小心花太多時間在已經很熟的科目（像國文或社會），反而像數學、自然這種不熟的弱科，最後排出來的進度根本讀不完。

市面上的排程 App 或表格大多只是把時間平均拉開，沒辦法依照我「對某一科到底熟不熟」來自動調配。因此我決定自己用 C++ 寫一個輕量化的排程工具，根據各科熟練度與章節進度，讓電腦幫我算出每天該讀哪一科、讀幾節課。

---

## 🛠️ 程式功能與技術實作

### 1. 自動計算倒數天數
利用 C++ 標準庫 `<ctime>` 裡面的 `mktime` 與 `difftime`，輸入考試日期與今天日期後，程式會自動轉換為秒數並計算剩餘天數，避免人工計算日期的誤差。

### 2. 弱科加權與 Credit 累積額度配節演算法
我將各科熟悉程度設定為 1～5 分（1 為極不熟、5 為非常熟練）：
* **加權公式**：$W_i = 6 - \text{Level}_i$，熟練度越低，算出來的權重越高。
* **Credit 累積配節**：程式會依據權重計算各科的分配額度（Credit），並在每日可用的節數內（一節 50 分鐘），每次優先挑選 Credit 最高的科目分配 1 節，同時扣除該科 1.0 的額度。這樣既能保證弱科拿到最多時間，也不會完全漏掉強科的複習。

### 3. 設定存檔與自動讀取 (`plan_data.txt`)
使用 `<fstream>` 的 `ofstream` 與 `ifstream` 處理資料讀寫。每次設定完成後會將考試名稱、日期、每日節數與各科進度寫入文字檔；下次開啟程式時會自動載入，不用重複輸入。

### 4. 步驟式嚮導與按 `b` 返回上一題
為了避免在終端機輸入資料時，只要打錯一個數字就必須整個程式重新執行的問題，我在 `setupWizard()` 中寫了步驟控制邏輯。只要輸入 `b` 或 `B`，程式就會觸發 `step--`，退回上一個輸入項目讓使用者修改。

### 5. 解決 Windows 終端機中文亂碼
為了解決 Windows CMD 預設編碼（CP950）導致繁體中文輸出變成亂碼的問題，我在 `main()` 程式進入點加入了 `system("chcp 65001 > nul");`，將控制台編碼強制轉為 UTF-8。

## 📐 核心資料結構

```cpp
// 科目結構體：記錄各科進度與熟練度
struct Subject {
    string name; // 科目名稱 (例如: 國文、數學)
    int level;   // 熟練度 1(不熟) ~ 5(很穩)
    int goal;    // 預計總章節數
    int done;    // 目前已完成章節數
};
